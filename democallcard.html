The golden path click this live, front to back

  1. 1
    New Lead/sales → Leads tab

    "+ New Lead" — company, contact, phone, email, source. Save.

  2. 2
    Convert to Customer + OpportunityLeads tab

    Click "Convert" on the row — one click creates both records.

  3. 3
    Quotation/sales → Quotations tab

    New quotation against the opportunity — add line items, save.

  4. 4
    Accept → Convert to SOQuotations tab

    Flip status to Accepted, then "Convert to SO" — same row.

  5. 5
    Convert to Project/projects (as design_head/admin)

    "Convert Sale Order" button — auto-seeds the full milestone chain + Scope of Supply.

  6. 6
    Engineering → BOMProject page → Engineering tab

    Add a BOM line. Or jump straight to a project already mid-BOM — see the stage map below.

  7. 7
    Procurement → Stores → Production → QC/procurement, /stores, /production, /qc

    Each has its own live pipeline board. Use the stage map to open a project already sitting at that exact stage instead of building one live.

  8. 8
    Dispatch/ops?dept=Dispatch

    Pack → link the Sales Invoice → set freight + e-way bill → dispatch → post freight to the ledger.

  9. 9
    Customer Portal/portal (as the customer)

    Log in as that customer — phase stepper, nested QC certificate + packing list, Billing card with the invoice. This is the payoff moment.

If the client asks about this, say so plainly honest limits

  • Customer credential emails aren't sending yet — the login/portal system is fully built and working (as shown above); actually emailing a real customer their password-setup link is blocked on picking a sending identity/provider. Every login you demo with was created directly, not emailed.
  • E-way bill is capture-only — the field exists and is real, but generating one against the government GSP API needs a paid integration, not built.
  • GTA reverse-charge GST on freight isn't modeled — freight posts as a flat expense.
  • If asked to invent a brand-new example live: fastest safe path is the golden path above on a throwaway name — don't overwrite one of the named example projects mid-call.
