1. Government e-way bill (needed before the app can create e-way bills)

Why: an e-way bill is created on the government's own system, so each company needs its own login to it. We cannot register for you.

Do this once for each company: Shanti Boilers and Shanti Techno Fab (and Srivaari Agencies if it will ship goods).

  1. Check with your CA that the company is allowed API access. The government allows it for roughly 1,000 e-way bills a day or 10,000 a month per GSTIN. If you are below that, tell us - we will find another route.
  2. Sign in to the e-way bill portal (ewaybillgst.gov.in) with the company's GST login.
  3. Go to Registration → For API and apply. Ask for test (sandbox) access first, so no real e-way bill is created while we test.
  4. When approved, the portal gives you four values: Client ID, Client Secret, API user name, API password.
  5. Give them to your Accounts head. They enter them in the app under Accounts → Company Entities → E-Way Bill credentials, then press Test Connection. Do not send these by email or chat.
  6. Tell us when this is done. We then switch the app to the government's server and run a test bill.
  • Shanti Boilers - API access applied for / received
  • Shanti Techno Fab - API access applied for / received
  • Credentials entered in the app by the Accounts head, Test Connection shows success

Why: GST invoice numbers must run in one unbroken series. The app must carry on from where your old system stopped.

  • Tell us the last invoice number issued for each company in this financial year (2026-27), for example SB/36/2026-27. We set the app to continue from the next one.

4. Customer and product details

Why: an e-way bill needs the customer's GSTIN, state, pincode and address, and every invoice line needs an HSN code. Only customers and products you actually ship or bill need this - not all of them.

  • Customers you will ship to: GSTIN, state, pincode and full address. Add them in Sales → Customers (the app lists what is missing when you try to create an e-way bill).
  • HSN code and GST % for each product you sell (about 950 products have none yet). Send us a sheet with product name, HSN, GST % and we load it, or fill it in Sales → Masters → Products.

5. Email (so quotations and portal invitations go out under your name)

Why: until a mailbox is connected, the app does not send any customer email. Nothing goes out by mistake meanwhile.

For each company:

  1. A sending mailbox in Zoho Mail, for example sales@your-company.
  2. Turn on two-step verification for that mailbox.
  3. Create an app password: Zoho Accounts → Security → App Passwords, named "Shanti Ops".
  4. Make sure SMTP is allowed for the mailbox (Zoho Mail → Settings → Mail Accounts → SMTP; on some plans an administrator must allow it).
  5. Tell us whether the Zoho account is on the India or .com server.

Then the Sales head enters the mailbox and app password under Settings → Sales → Email, presses Send test email, and switches from Test to Live once it works.

Only about 300 of your 9,500 customers have an email address. For everyone else, portal links are shared with the Copy link button (for example over WhatsApp).

6. WhatsApp (later — only if you want the app to send WhatsApp messages itself)

Today WhatsApp works from your own phone: the app opens WhatsApp with the message ready. Automatic sending needs the official WhatsApp Business service from Meta, which you pay per message.

  1. A Meta Business account, verified with your company documents.
  2. A phone number that is not already used on the WhatsApp app (a new SIM or a landline).
  3. A payment card on the Meta account. Roughly ₹0.12–0.15 per business update message (RFQ, order status) in India; promotional messages cost more.
  4. Message templates (RFQ, order update) approved by Meta — we draft them for you.

Then you paste the access token and phone number ID into Settings, the same way as the email password. We recommend Meta's own service directly (no middle company fee). If you prefer a company with a dashboard and phone support, AiSensy, Interakt or Gupshup work too, for a monthly fee on top of the message cost.
